## Dataset terms remain separate from model license declarations

The Kev model card separately declares Apache-2.0 for the adapter and head, and identifies the Qwen base as Apache-2.0. Those model declarations do not resolve the dataset entries above. The dataset table reports HF metadata, not verified upstream license texts or a conclusion about whether any dataset terms affect trained weights or a particular redistribution. `unknown`, `other`, absent metadata, mixed licenses, and unreviewed source agreements remain unresolved.
